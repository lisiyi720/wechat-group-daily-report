# 群消息日报模板

# 群消息日报｜YYYY-MM-DD

> 统计区间：YYYY-MM-DD 00:00:00—次日 00:00:00（配置时区）  
> 数据说明：微信 X 个来源、共 X 条；飞书/Lark X 个来源、共 X 条。

## 1. 今日总览

1. **观点标题。** 说明事实、判断和影响。==最重要结论用高亮。==
2. **观点标题。** 提炼当天的重要机会、风险或趋势。
3. **观点标题。** 说明这些信息对报告使用者有什么价值。

## 2. 分来源重点

### 2.1 来源名（微信/飞书）

1. **观点标题。** 说明事实与判断，必要时保留原始 URL。
2. **链接情况。** 原链接未被 CLI 解析时明确标注；飞书有 `message_app_link` 时可补充。

### 2.2 当天无消息来源

1. 来源名：0 条。

## 3. 跨群趋势

1. **==趋势一：标题。==** 合并多个来源的共同信号并解释影响。
2. **==趋势二：标题。==** 不重复分群摘要，给出更高一层判断。

## 4. 高价值附件与链接（最多 3 个）

1. **条目标题**
   - 来源群：
   - 发送人：
   - 原链接：没有时写“无，CLI 未解析出原 URL”
   - 内容概述：
   - 价值判断：==为什么值得回看。==
   - 建议处理：

没有足够价值时写：今日未发现值得单独归档的附件或链接。

## 5. 可用素材

1. **可直接表达的观点**
2. **文章/视频选题**
3. **值得深挖的人或话题**

## 6. 后续可跟进

1. **跟进项标题。** 写清楚下一步动作和目的。
2. **跟进项标题。** 只保留真正值得做的事。
